# tools

## to_md.py — 문서를 읽기 쉬운 md로 일괄 변환

폴더 아래 문서를 같은 이름의 `.md`로 변환하고, 원본은 이름 앞에 `[md변환전]`을 붙여 남긴다(삭제하지 않음).

| 원본 | 처리 |
|---|---|
| `.md` `.txt` | 이스케이프(`\~` `\#`) 정리, 들여쓰기 개요는 중첩 불릿으로 |
| `.docx` | 제목·목록·굵게·표를 md로 |
| `.pdf` (텍스트 PDF) | `pdftotext`(poppler)로 추출 |
| `.hwp` (HWP5) | 표준 라이브러리로 직접 파싱, 표는 셀 좌표로 복원 |
| `.html` `.htm` | 정적 본문(제목·문단·목록·표) + **클릭·스크립트로 나중에 표시되는 동적 콘텐츠**(아래 설명). `tools/html_to_md.py` |
| 스캔 PDF, `.png` `.jpg` | 자동 변환 불가 → 목록으로 출력. Claude가 눈으로 읽어 같은 이름 `.md`를 쓴 뒤 `--finalize` |

```
python -I tools/to_md.py <폴더>              # 미리보기(바꾸는 것 없음)
python -I tools/to_md.py <폴더> --apply      # 변환 + 원본에 [md변환전] 접두어
python -I tools/to_md.py <폴더> --finalize   # 이미지·스캔 PDF 원본에도 접두어(같은 이름 .md가 생긴 것만)
옵션: --skip 문자열 (경로에 포함되면 제외, 기본 "[기본폴더구조]")  --prefix 문자열 (기본 "[md변환전]")
```

- HTML 동적 콘텐츠: JS를 실행하지 않고 `<script>`의 데이터 리터럴(`const itemData = [{…}]` 등)을 파싱해 `## 동적 콘텐츠` 절로 붙인다.
  항목별 제목·가이드·선택지(표)로 구조화하고, 필드 라벨은 화면에 꽂는 코드·템플릿·DOM 위치에서 자동 유추한다. 분류값(예: road/drain)은
  해당 영역 제목으로 묶는다. if/else 조건별 표시 문구와 차트 라벨도 표로 뽑는다. 한계: 서버에서 fetch로 불러오는 데이터나 복잡한 식으로
  계산되는 값은 추출하지 못한다.
- 다시 실행해도 안전하다: 접두어가 붙은 원본과, 변환본 머리말(`> 원본: …`)이 있는 md는 건너뛴다.
- 같은 이름의 원본이 여러 형식이면 md/txt가 `이름.md`, 나머지는 `이름_docx.md` 식으로 구분한다.
- 한계: PDF·hwp는 다단 레이아웃·서식·도장·체크박스를 완벽히 복원하지 못한다. 암호 걸린 hwp, 구버전 hwp, hwpx는 실패로 보고한다.
- 요구: Python 3.8+ (표준 라이브러리만), 텍스트 PDF는 `pdftotext`가 PATH에 있어야 한다.
